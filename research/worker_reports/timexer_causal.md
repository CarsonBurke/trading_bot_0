## Row layout (corpus schema `timexer-pooled-mmap-v3`)
Packed row = `L*4 log_prices (ln p − ln c_ctx, OHLC) | L valid | L*n_aux aux (history channels 0/validity 0 beyond context) | 1 anchor (c_ctx)`, L = 6192, width 6192·(4+1+12)+1 = 105,265 f32 for `--features all`. Device tensors: `log_prices [B,L,4]`, `valid [B,L]`, `aux [B,L,12]`, `anchor [B]`. No CPU σ/range/geometry.

## Shapes / memory at B=256 (375 origins, 192 horizon, 12 aux, 6 known)
tokens [256,375,16·16=256]→bf16 state [256,375,512] (~98 MB bf16/layer activations); known covariate window [256,375,1152] bf16 221 MB; head output [256,375,192,8] fp32 590 MB; targets/scaled/nll-elements each [256,375,192,4] fp32 295 MB (~74M elements); mask [256,375,192] 74 MB. Backbone params 8·(4·512²+2·512·2048) ≈ 25M; head 1024×1536 ≈ 1.6M + covariates 1152×256.

## Open design decisions taken
- Baseline NLL/MSE in score is the flat `ŷ=0, s=√h` forecast (spec definition, keeps MSE comparable to current run). The zero-weight head yields the persistence *candle* (open=close=c_k exactly; high/low from ρ_k via the retained joint decoder), so init NLL equals the baseline on open/close channels exactly and differs on high/low (unit test verifies init NLL == by-hand persistence-candle NLL at every origin).
- σ-scaled aux channels (volume/market/spy innovations) are divided by σ_k at the token like prices; calendar/gap channels enter unscaled. `min_history` counts valid bars ≤ t_k; origins below it are masked from the loss (row's own stats still computed). Variance floor 1e-8 kept. Output layer zero-init; covariate projection 256 wide, head hidden 1024. Manifest `validation_nll` selects best checkpoint; `validation_mse` retained for reporting. Old objective `logreturn_sigma_mse_v1` / format `timexer-ohlc-universe-v4` rejected with explicit error (tested).
