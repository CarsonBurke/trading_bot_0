# CausalPatch review — trading_bots/src/torch/timexer_segment (working tree, 2026-09-05)

Verdict: **CANCEL RUN** (one demonstrated numerical bug in the token input path; no leakage found).

## Demonstrated bugs

### B1 (P1) — market/SPY *validity flags* are divided by σ_k, injecting ~1/σ ≈ 500–2000 constants into the bf16 residual stream
- `features.rs:56-58` `Feature::sigma_scaled` = Market|Spy; `features.rs:136-139` `channel_mask` repeats the role for **both** channels of a feature (`WIDTH = 2`), so the mask is `[.., false,false, true,true, true,true]` (asserted by the test at `features.rs:532-535`): channels 9 and 11 — the 0/1 validity flags of market and SPY — are marked σ-scaled.
- `model.rs:407-411`: `aux * (sigma_scale * inv_sigma + unit_scale)` therefore writes `1/σ_k` into 32 of the 256 entries of every context token (16 bars × 2 flags). Realistic five-minute σ is 5e-4–2e-3 (floor 1e-4), i.e. values of 500–2000 (up to 1e4) next to price entries of rms ≈ 2–4.
- Consequence at init (`projection` bound 1/√256): patch-linear output rms ≈ 140 from the flags vs ≈ 0.7 from the 64 price entries (measured with the exact layout, W~U(±1/16), 1/σ = 700: residual rms 140.3, price contribution rms 0.72). The token is cast to bf16 at `model.rs:412-414` and the residual stream stays bf16 for all 8 blocks (`model.rs:176-213`): bf16 spacing at 140 is 1.0, so every price/attention/FFN contribution (rms ≈ 0.5–1) is quantized with error rms ≈ 0.32 per add (measured corr 0.91 per op), compounding over 8×(LN1, attn-add, LN2, ffn-add). The backbone is effectively driven by a per-origin constant direction scaled by 1/σ_k; the σ-normalisation that the whole design relies on is undone for this channel. AdamW will try to shrink those 32 columns (grad ∝ 700× larger, Adam-normalised, lr 0.008, wd×150), but the equilibrium noise ±lr·700·√32 ≈ ±30 stays ≫ 1.
- Not leakage; the flags are causal. But it is unintentional (design doc: "σ-scaled ones divided by σ_k; calendar/gap channels enter unscaled" — a 0/1 flag is not an innovation) and it changes the effective numerics of the entire backbone.
- Fix sketch: scale only the value channel of each σ-scaled feature, e.g. in `CausalPatchModel::new`:
  `let sigma_scale: Vec<f32> = config.features.features().flat_map(|f| [f32::from(u8::from(f.sigma_scaled())), 0.0]).collect();`
  (and keep the `channel_mask(Feature::sigma_scaled)` helper for tests, or change `channel_mask` to take `fn(Feature, usize) -> bool`). Optionally also clamp the multiplier (`inv_sigma.clamp_max(1e3)`) for the return channels. Re-run the 26 unit tests; `head_covariates_ignore_history_channels_beyond_the_context` / `zero_head_forecasts_persistence…` are unaffected.

## Hypotheses (not demonstrated) + resolving check
- H1 Baseline comparability with "the previous run": HEAD's `fill_row` scaled by a *close-price* std (`close_scale = √(m2/context + 1e-5·std²)`), not a log-return σ; if the previous run is that code, σ-scaled MSE/persistence MSE are in different units. Check: the preview `persistence_mse` at step 1000 is a data-only quantity — it must equal the previous run's preview persistence MSE on the same fixed 2048 origins if the units match.
- H2 fp32 one-pass variance `E[r²]−mean²` (`model.rs:352-362`): with r≈1e-3, mean²≈1e-10 ≪ E[r²]≈1e-6 there is no cancellation; cumsum rounding ≈ √6000·6e-8·6e-3 ≈ 3e-8 absolute on a 6e-3 sum (5e-6 relative). Adequate. Only a split/unadjusted jump (r≈0.7) would dominate the sum — but that is a data issue, and the fp64 reference test would still agree. No action.
- H3 Known-future `SessionGap` for horizon bars is computed from realized future timestamps (`features.rs:389-401`), so a quarantined/missing future bar shows up as a gap flag one bar later. Calendar-level, by design; check: share of horizon bars with gap flag = 1 vs. context share.
- H4 Rows at the train/validation boundary with `targets < pred_len` have zero *calendar* covariates for bars beyond `targets` (`fill_row` writes nothing there). Masked in the loss; only affects the head input for the last few origins of those rows. Harmless.
- H5 AdamW `weight_decay 0.005 × 150` on `patch.`/`covariates.`/`head.` (`compute.rs:111-115`) copies nanogpt's embed/head multiplier; with a 256-wide σ-scaled input this is untested. Check: norm of `patch.weight` after 1k steps.
